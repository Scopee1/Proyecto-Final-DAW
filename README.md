# Futbolle

Juego de adivinanza de jugadores de futbol al estilo Wordle, desarrollado como Proyecto Final Individual de Desarrollo y Arquitecturas Web 2026 (UAI).

## Descripcion

Al iniciar la partida el juego obtiene un jugador secreto desde el endpoint de la catedra. El usuario tiene 8 intentos para adivinarlo escribiendo nombres en un campo con autocompletado. Cada intento devuelve pistas visuales comparando nacionalidad, club, posicion, edad, overall y altura contra el jugador secreto.

## Tecnologias

- HTML5
- CSS3 (maquetado con Flexbox)
- JavaScript ES5 en modo estricto
